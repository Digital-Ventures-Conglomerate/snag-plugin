# Snag for Claude Code

Turn Snag bug reports (replay, console, network) into fix PRs from Claude Code.

## Install

```sh
claude plugin marketplace add Digital-Ventures-Conglomerate/snag-plugin
claude plugin install snag@snag-plugin
```

Snag captures what a user saw when they hit a bug: the session replay, console errors and failed network requests. This plugin connects Claude Code to that evidence so it can find the cause in your repo and prepare a pull request for a human to review. A Snag workspace is required: https://snag.ac

More documentation is coming with the first release.
